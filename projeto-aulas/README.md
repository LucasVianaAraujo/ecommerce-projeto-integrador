# Projeto de aula - versão VISUAL (HTML + CSS)

Recriação do e-commerce **OldShoes** usando apenas o conteúdo dos slides das aulas.
Esta branch tem **somente a parte visual**: páginas HTML e CSS, sem nenhum JavaScript.
As listas (produtos, carrinho, pedidos, tabela do admin) mostram dados de exemplo escritos direto no HTML.

Abra `index.html` no navegador (não precisa de servidor nem de instalação).

Páginas: `index`, `produtos`, `categorias`, `exibir-produto`, `carrinho`, `login`, `cadastro`,
`recuperar-senha`, `perfil`, `admin`, `admin-produtos`, `admin-produto-form`.
